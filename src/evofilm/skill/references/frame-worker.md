# Frame worker — building one frame

You build ONE frame: `compositions/frames/<frame_id>.html`. Read, in order: your role file
(`.evofilm/packets/_role.md`), your packet (`.evofilm/packets/<frame_id>.md` — storyboard block,
film-wide direction and the spoken word times), the project's `frame.md`, then this file and
`quality-bar.md` (next to this file). Your packet's `route:` names the drawing technique — open the
matching recipe: `styles.md` (named looks), `history.md` (maps, period images), `solve.md` (worked
problems, formulas, strokes), `techniques.md` (simulations, rigs, infinite zoom, footage).
HyperFrames' own composition contract (`npx hyperframes docs`) applies; where this file is stricter, it wins.

When you are done: `evofilm lint --project <project> --frame <frame_id>` must report no errors —
it checks the non-negotiables below plus every rule learned from past films.

## Non-negotiables (each one broke a real EvoFilm render or lint)

1. **File shape** — exactly one bare `<template>…</template>`; every `<style>`/`<script>` inside it;
   root `<div id="root" data-composition-id="<frame_id>" data-width="W" data-height="H">` (W×H = the canvas in your packet: 1920×1080, 1080×1920 or 1080×1080),
   styled only via `#root`. One `gsap.timeline({ paused: true })` → `window.__timelines["<frame_id>"]`.
2. **Ids** — every `class="clip"` element has an id (`<prefix>-ground`, `<prefix>-stage`) and
   `data-start` / `data-duration` / `data-track-index`. Prefix every id and class with a short frame
   prefix (e.g. `f04-`) — siblings share one document.
3. **Ground** on its own full-duration clip layer, never a background on `#root`.
4. **Fonts** — only families that ship as files. Paste the needed `@font-face` lines from
   `assets/fonts/font-faces.css` (generated by `evofilm fonts`) into your `<style>`. Chinese text →
   `"Noto Serif SC"` (display) / `"Noto Sans SC"` (labels); numbers → `"JetBrains Mono"` (bundled).
   A Latin display face may lead the stack (`"Instrument Serif", "Noto Serif SC", serif`).
5. **SVG transform origins** — when a tween sets `svgOrigin`, put the SAME `svgOrigin` in BOTH the
   from-vars and the to-vars of `fromTo`. Origin only in `to` leaves a residual offset (arrows drift
   away from their anchor).
6. **Repeated fromTo on one target** — every later `fromTo` on the same element gets
   `immediateRender: false`, or merge the properties into one tween.
7. **No negative z-index** — paint order by DOM order: underlay element first, then the text in a
   later `position: relative` span.
8. **Caption band** — nothing that matters inside the bottom 16.67 % of the canvas (below y = 900 on 1920×1080,
   y = 1600 on 1080×1920 — your role file states it). Ground/ambient layers may bleed. On 9:16, use the height:
   title/working zone at the top, the hero in the middle, a second working zone above the band.
9. **Blooms / glows that bleed off-canvas** carry `data-layout-allow-overflow`.
10. **Determinism** — no `Math.random`, `Date.now`, `requestAnimationFrame`, CSS transitions. Use the
    seeded PRNG below. Every pixel is a function of timeline time.
11. **No exit tweens** except in the final frame; the transition injector owns frame exits.
12. **No narration sentences on screen.** Labels, numbers, one short hero word.
16. **Reveal masks use butt caps** — a mask stroke with `stroke-linecap: round` leaks a dot at the
    start of a not-yet-drawn stroke (stray ink dots); use `butt` on reveal-mask paths.
13. **Draw-on paths** — never put a `stroke-dasharray` attribute in the markup of a path you
    animate; set dasharray/offset only in the tween (the attribute made a route render fully drawn).
14. **Local data/images** — map data via `<script src="assets/geo/…js">` (classic, before your
    script); images only from `public/` (Commons downloads are already there and credited).
15. **Film-wide elements are not yours** — a timeline ribbon or chapter bar that spans frames is an
    overlay (`compositions/overlays/`), built by the orchestrator; leave its band (y 40–110) clear
    if the brief says one exists.

17. **Shared kit first** — if your role file lists `assets/<film>-kit.js`, load it and build on it (figure
    coordinates, strokes, draw/write helpers) instead of redrawing; match the approved frames it lists.

```html
<div id="f04-stage" class="clip" data-start="0" data-duration="D" data-track-index="1">
  <div class="f04-world" id="f04-world">          <!-- the camera: one move across the frame -->

    <div class="f04-mid"  id="f04-mid"></div>     <!-- haze, context objects -->
    <div class="f04-hero" id="f04-hero"></div>    <!-- the thing being explained -->
  </div>
  <div class="f04-labels">…</div>                 <!-- labels stay screen-stable -->
</div>
```

```js
// camera: a slow push for the whole frame, plus parallax on the layers
tl.fromTo("#f04-world", { scale: 1.0 }, { scale: 1.08, duration: D, ease: "sine.inOut" }, 0);

```

## Hero scale and camera — checkable minimums (the #1 judge complaint: hero too small, camera static)

- Hero bounding box ≥ 900×540 px on 1920×1080 (≈ half the frame), centred in the y 0–900 band; if the
  hero is a thin line-art object, draw it bigger, not more of it. Add fill (gradient + highlight/glow),
  not outline only. Many-item heroes (raindrops, troops, ships) use ≥ 40 items, not 5.
- The camera move must be visible in a still: scale 1.0→≥1.25 (or a pan ≥ 150 px, or orbit ≥ 25°) over the
  frame, with the focus point set via `transformOrigin` on the thing being explained. Across the frame the
  camera position visibly changes, not just the labels added. `1.0→1.08` above is the *idle* minimum only.
- Ground layer is `inset:0` (never a negative inset); element ids start with a letter (`f4-…`), never a digit.
- Keep labels out of the hero's bbox and the ray/line paths (≥ half the font height from any line).
- Never let the last-frame SFX run past the end: cue closing chime/impact ≥ 1.7 s before the film ends.

## Seeded PRNG (use for every "random" layout)

```js
function rng(seed) { return function () { seed |= 0; seed = (seed + 0x6D2B79F5) | 0;
  let t = Math.imul(seed ^ (seed >>> 15), 1 | seed); t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
  return ((t ^ (t >>> 14)) >>> 0) / 4294967296; }; }
const rand = rng(42);
```

## Procedural layers with Canvas 2D (particles, fields, flows, star fields)

Drive the canvas from the GSAP timeline with a proxy tween — seek-safe, works in sub-compositions:

```html
<canvas id="f04-canvas" width="1920" height="1080" data-layout-allow-overflow style="position:absolute;inset:0;width:100%;height:100%"></canvas>
```
```js
const ctx = document.getElementById("f04-canvas").getContext("2d");
const rand = rng(7);
const stars = Array.from({ length: 220 }, () => ({ x: rand() * 1920, y: rand() * 1080,
  r: 0.6 + rand() * 1.6, a: 0.2 + rand() * 0.6, p: rand() * Math.PI * 2, depth: 0.3 + rand() * 0.7 }));
function draw(t) {                       // t = seconds into this frame
  ctx.clearRect(0, 0, 1920, 1080);
  for (const s of stars) {
    const tw = 0.65 + 0.35 * Math.sin(t * 1.3 + s.p);          // twinkle
    ctx.globalAlpha = s.a * tw;
    ctx.beginPath(); ctx.arc((s.x - t * 6 * s.depth + 1920) % 1920, s.y, s.r, 0, Math.PI * 2);
    ctx.fillStyle = "#ECE8DC"; ctx.fill();
  }
}
const clock = { t: 0 };
tl.to(clock, { t: D, duration: D, ease: "none", onUpdate: () => draw(clock.t) }, 0);
draw(0);
```
Plain-object proxies (clocks, counters) use `tl.to(obj, …)`, not `fromTo` — two proxy `fromTo`s
trip `gsap_repeated_fromto_without_baseline`. A full-bleed canvas carries `data-layout-allow-overflow`
(else `canvas_content_at_edge`).

Particles that *travel* (light rays, molecules, airflow): compute each particle's position as a pure
function of `t` (start time, speed, path) — never integrate state frame to frame.

## Real 3D with Three.js (planets, molecules, atmosphere shells, orbits)

```html
<canvas id="f04-three" style="position:absolute;inset:0;width:100%;height:100%"></canvas>
<script type="module">
  import * as THREE from "https://cdn.jsdelivr.net/npm/three@0.181.2/+esm";
  const D = 9.4;
  const renderer = new THREE.WebGLRenderer({ canvas: document.getElementById("f04-three"), alpha: true, antialias: true, preserveDrawingBuffer: true });
  renderer.setSize(1920, 1080, false); renderer.setPixelRatio(1);
  const scene = new THREE.Scene();
  const camera = new THREE.PerspectiveCamera(35, 1920 / 1080, 0.1, 100);
  const planet = new THREE.Mesh(new THREE.SphereGeometry(1.6, 96, 96),
    new THREE.MeshStandardMaterial({ color: 0x2a5bd7, roughness: 0.55 }));
  scene.add(planet, new THREE.AmbientLight(0x8899ff, 0.35));
  const sun = new THREE.DirectionalLight(0xffe2a8, 2.2); sun.position.set(4, 2, 3); scene.add(sun);
  function renderAt(t) {
    camera.position.set(Math.sin(t * 0.08) * 0.6, 0.2, 7 - t * 0.12);   // slow push-in
    camera.lookAt(0, 0, 0);
    planet.rotation.y = t * 0.15;
    renderer.render(scene, camera);
  }
  const clock = { t: 0 };
  const tl = gsap.timeline({ paused: true });
  tl.to(clock, { t: D, duration: D, ease: "none", onUpdate: () => renderAt(clock.t) }, 0);
  // …other DOM/SVG tweens for labels go on the same tl…
  renderAt(0);
  window.__timelines["04-planet"] = tl;   // register only after the build is complete
</script>
```
Verified in render (EvoFilm smoke test, hyperframes 0.8.127). Load the GSAP `<script src>` (classic)
before this module. Surfaces: paint an equirectangular `THREE.CanvasTexture` (smooth coastlines, clouds,
bands) rather than per-vertex colors, which look blocky up close. Keep geometry procedural (no model/texture
fetches at seek time). A star field behind it is cheaper as a Canvas 2D layer than in WebGL.

## Hand-drawn line art (notebook preset)

Wobbly pen strokes — perturb points with the seeded PRNG, draw them on with stroke-dashoffset in the
order the narration names them, then fill marker color slightly offset from the outline:

```js
function wobblyPath(points, amp, rand) {          // points: [[x,y],…] → smooth jittered path
  const p = points.map(([x, y]) => [x + (rand() - 0.5) * amp, y + (rand() - 0.5) * amp]);
  let d = `M${p[0][0]},${p[0][1]}`;
  for (let i = 1; i < p.length; i++) {
    const [x0, y0] = p[i - 1], [x1, y1] = p[i];
    d += ` Q${x0},${y0} ${(x0 + x1) / 2},${(y0 + y1) / 2}`;
  }
  return d + ` T${p[p.length - 1][0]},${p[p.length - 1][1]}`;
}
```

## Embedded Manim clip (formula derivations, function graphs)

Render the clip with Manim at 1920×1080, background = frame.md canvas color, duration ≤ the frame:
`manim -qh --fps 30 -c "<canvas hex>" scene.py Derive -o derive.mp4`
then place `assets/manim/derive.mp4` as a **muted** `<video class="clip" id="f05-derive" …>` that is a
direct child of `#root` (never inside another timed element), labels and camera on top.
